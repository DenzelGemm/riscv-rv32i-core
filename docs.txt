Базові підмодулі ядра (Single-Cycle & Pipeline Datapath)
    rv32i_core.sv (або riscv_core.sv) — Top-level модуль ядра, що об'єднує всі блоки.
    regfile.sv (або register_file.sv) — 32-розрядний регістровий файл ($32 \times 32$ біт з фіксованим нулем у x0, 2 порти читання, 1 порт запису)
    alu.sv — Арифметико-логічний пристрій (ADD, SUB, SLT, SLTU, XOR, OR, AND, SLL, SRL, SRA)
    imm_gen.sv (або imm_decoder.sv) — Генератор констант (знакове розширення для форматів I, S, B, U, J)
    branch_comp.sv (або branch_unit.sv) — Блок перевірки умов розгалуження (BEQ, BNE, BLT, BGE, BLTU, BGEU)
    lsu.sv (Load-Store Unit або byte_mask_gen.sv) — Логіка маскування та вирівнювання байтів/напівслів (LB, LH, LW, LBU, LHU, SB, SH, SW)
    pc_reg.sv — Регістр лічильника команд (Program Counter).Блоки керування (Control)
    ctrl_unit.sv (або control_unit.sv) — Головний блок керування (декодує opcode та формує сигнали запису в регістри, вибору джерела ALU, читання пам'яті тощо)
    alu_ctrl.sv (або alu_decoder.sv) — Декодер операцій ALU (визначає конкретну операцію ALU на основі funct3, funct7 та типу команди)

Специфічні підмодулі для 5-Stage 
    pipelinepipe_reg_if_id.sv, pipe_reg_id_ex.sv, pipe_reg_ex_mem.sv, pipe_reg_mem_wb.sv — Міжстадійні конвеєрні регістри
    hazard_unit.sv — Блок керування апаратними конфліктами (Stall конвеєра при Load-Use Data Hazard, Flush при Branch Misprediction)
    forwarding_unit.sv (або bypass_unit.sv) — Блок перенаправлення даних (Forwarding з стадій EX/MEM та MEM/WB напряму на вхід ALU).
